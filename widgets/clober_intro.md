# Clober
Clober is a fully on-chain orderbook DEX protocol enabling capital-efficient trading and liquidity provision. Unlike AMM-based DEXs, Clober uses a Central Limit Order Book (CLOB) model for precise price discovery and minimal slippage.
### Key Features
- **On-chain Orderbook**: Fully decentralized limit order trading
- **Liquidity Vaults**: Automated market-making strategies for LPs
- **Multi-chain**: Deployed on Base and Monad
